# U Can Win – The Life Uplifting Center

Soft pastel & 3D claymorphism website built with **Vite + React** for **U Can Win – The Life Uplifting Center**, founded by **Upama Kalita**.

## Quick Start

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Highlights

- Soft pastel palette (sage mint, buttercup sunshine, lavender mist, peach blossom, warm cream) paired with bespoke 3D clay illustrations (WebP-optimized).
- All 13 services with interactive focus-area filters and direct pre-filled WhatsApp enquiry buttons (`6001629199`).
- Dedicated Online Sessions section for Zoom & Google Meet, Upama Kalita's credentials, interactive Enquiry Builder (WhatsApp + Email), and FAQ accordion.
- Enquiry-based pricing (no prices shown) and authentic trust elements (no fabricated testimonials).
